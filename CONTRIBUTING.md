# Contributing to NanoMetrics

Thank you for your interest in contributing to NanoMetrics! We welcome contributions from the community to help make this privacy-focused analytics platform even better.

## How to Contribute

### Reporting Bugs

1. Check existing issues to avoid duplicates
2. Use the bug report template
3. Provide detailed steps to reproduce
4. Include system information and error messages

### Suggesting Features

1. Check if the feature already exists or is planned
2. Open a feature request issue
3. Describe the use case and benefits
4. Discuss implementation approaches

### Code Contributions

1. **Fork the repository**
2. **Create a feature branch**: `git checkout -b feature/your-feature-name`
3. **Make your changes**
4. **Add tests** for new functionality
5. **Ensure all tests pass**
6. **Follow code style guidelines**
7. **Commit with descriptive messages**
8. **Push to your fork**
9. **Create a Pull Request**

## Development Setup

Please refer to the main [README.md](README.md) for detailed setup instructions.

## Code Style

### Java Services
- Follow Google Java Style Guide
- Use meaningful variable and method names
- Add JavaDoc for public methods
- Ensure proper error handling

### Node.js Services
- Use Prettier for formatting
- Follow ESLint rules
- Use meaningful variable names
- Add JSDoc comments for complex functions

### Go Services
- Use `go fmt` for formatting
- Follow Go conventions
- Add comments for exported functions
- Use proper error handling patterns

### Frontend (React/TypeScript)
- Use TypeScript for type safety
- Follow React best practices
- Use meaningful component and variable names
- Implement proper error boundaries

## Testing

- Write unit tests for new functionality
- Ensure integration tests pass
- Test edge cases and error conditions
- Maintain or improve code coverage

## Pull Request Guidelines

- Keep PRs focused and atomic
- Write clear PR descriptions
- Reference related issues
- Ensure CI checks pass
- Be responsive to review feedback

## Community Guidelines

- Be respectful and inclusive
- Help others learn and grow
- Focus on constructive feedback
- Follow the code of conduct

## Questions?

- Open a discussion on GitHub
- Ask in existing issues
- Review documentation first

Thank you for contributing to NanoMetrics! 🎉
